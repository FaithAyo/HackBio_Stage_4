### **Introduction**
The Functional Enrichment Analysis App is an interactive R Shiny web application developed to analyze gene sets for functional enrichment. It specifically utilizes two key functions from the TCGAbiolinks package in R: `TCGAanalyze_EAcomplete()` and `TCGAvisualize_EAbarplot()`. These tools allow users to explore enriched Gene Ontology (GO) terms and pathways based on gene expression data. The app is designed for bioinformaticians and researchers who want to perform quick and efficient functional enrichment analysis with a user-friendly interface.

---

### **App Functionality**

The app consists of three main sections:

1. **Home**: Offers an introduction to the app and basic navigation instructions.
2. **Enrichment Analysis**: 
   - Users can input a list of genes, select enrichment types (Biological Process, Cellular Component, Molecular Function, and Pathways), and run the enrichment analysis.
   - The results are displayed in an interactive table format, and users can visualize the top enriched categories using a bar plot generated by `TCGAvisualize_EAbarplot()`.
3. **Contact**: Displays contact information for inquiries or feedback.

---

### **Methods Used for Analysis**

- **Enrichment Analysis**: The core of the app is based on the `TCGAanalyze_EAcomplete()` function, which classifies genes into categories based on their overrepresentation in Gene Ontology (GO) terms and pathways. 
- **Visualization**: The `TCGAvisualize_EAbarplot()` function is used to generate bar plots of the top enriched terms, making it easier for users to interpret their data.
- **Data Handling**: The app processes input gene lists and splits them into appropriate formats for analysis. It allows users to choose from multiple enrichment types (Biological Process, Cellular Component, Molecular Function, and Pathways) and view results interactively.

### **Challenges Encountered**

Several challenges arose during the app's development:

- **Task Understanding**: Initially, fully grasping the task's requirements and replicating the original ShinyGO app proved difficult. However, continued discussion and research helped clarify the objectives.
- **Package Dependencies**: Installing the necessary R packages was challenging due to missing dependencies, which required multiple iterations and troubleshooting.
- **Deployment Issues**: Server timeout errors occurred while deploying the app, slowing down progress. These errors were eventually resolved after several attempts.
- **Time Constraints**: Meeting deadlines was a challenge as we balanced development with these technical issues. Adjustments were made to ensure the app was functional within the given time frame.
- **Visualization**: Fine-tuning the parameters for meaningful and informative bar plots was essential to ensure clear and concise visual output.

---

### **Conclusion**

The Functional Enrichment Analysis App successfully integrates key functions from the TCGAbiolinks package to perform gene set enrichment analysis. Despite facing challenges related to package installation, server deployment, and visualization tuning, the app provides a streamlined and interactive tool for bioinformatic analysis. It simplifies the process of identifying significant GO terms and pathways for a user-specified gene set, offering both tabular and graphical results to aid in data interpretation.
